## 统计边界

- 单个任务，不能据此宣称总体成功率、误报率、效率提升或平均成本。
- 完整 usage 包含重复调用，不能当作独立需求数；中断请求可能没有最终 usage，Token 是已记录数据。
- 阶段墙钟时间可能包含中断恢复间隔；检查耗时取实际进程计时。
- API 与 Worker 共三个外部基础设施集成用例跳过，本次实际 HTTP 验证使用依赖故障替身。
- 没有人工基线，也没有已标注缺陷集，因此暂不能测意见误报率、漏检率或人效提升。
